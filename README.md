# 日历拼图

照着实物 1:1 复刻的网页版日历拼图：一块刻着 月 / 日 / 星期 的拼盘，十块木拼块。
每天把十块全部放进拼盘，只露出当天的「几月、几号、星期几」三格。

纯前端，没有任何网络请求，也不存进度：重新打开或刷新页面，就是重新玩一局。没有声音。

## 运行

```bash
npm install
npm run dev      # 开发，默认 http://localhost:5173
npm run build    # 打包到 dist/，静态文件可直接部署
npm test         # 规则与求解器测试
```

## 怎么玩

| 操作 | 鼠标 | 触屏 |
| --- | --- | --- |
| 移动 | 按住左键拖动 | 拖动 |
| 旋转 | 左键单击（绕点到的那一格转） | 轻点；拖着时另一根手指轻点 |
| 翻面 | 右键单击（拖着时也行） | 选中后点上方的「翻面」 |

拼块只用鼠标（或手指）摆弄，没有键盘快捷键，滚轮也不转拼块。

- 不会玩就点右上角的「玩法」：桌面上盖出一份玩法指引，一步一页，每页一段会动的小演示加一句话——要拼成什么、怎么拖动、怎么旋转、怎么翻面。
  点「下一步」往后翻，最后一页点「开始」收起；指引没收起来之前，底下的拼盘和拼块都点不动。
  电脑上讲的是左键、右键，触屏上讲的是轻点和拼块上方的「翻面」。
  指引不会自己弹出来，什么时候想看都可以再点「玩法」。
- 几块叠在一起时，点被压在下面的那块，第一下只把它拿到最上面，再点一下才旋转 / 翻面；触屏轻点也一样。
  谁压着谁按最后碰过的先后来定，放进拼盘里的拼块也一样。
- 拖到拼盘上方时会用虚线标出落点，靠近空位时拼块会被轻轻吸过去，松手就卡进格子。
- 在拼盘里旋转或翻面时，如果原地放不下，会自动挪到 2 格以内放得下、且仍压着你点的那一格的位置；实在放不下就搁在拼盘上面，等你再挪。
- 每天只拼当天的日期：拼盘上红笔圈出的三格，就是今天要露出的月、日、星期。
  「当天」按打开页面的那一刻算：页面一直开着过了零点，不会自己换成新的一天，拼盘和拼块都原样不动；
  刷新或者重新打开，才是新一天的新一局。
- 拼好之后，托盘那一侧马上显示「恭喜，拼好了！」、当天的日期和用时、一句夸奖（共八句，每天换一句）和「明天再来，新的一天仍然要拼！」，上面没有按钮。
  过一秒才放礼花，免得太突然：左下、右下两个礼花筒各喷两次，空中再炸开几团，彩纸慢慢飘落，五六秒后自己收场。
  这一秒里又把拼块拿出来，就不放了；点左上角的「全部收回」重拼一遍，再拼好时会再放。系统开了「减少动态效果」就不放礼花，只显示文字。
- 「用时」从这一局第一次动拼块（开始拖、单击旋转或右键翻面）算起，到最后一块放进去、拼好的那一刻为止，
  按钟表时间算，中途切到别的页面的时间也在内。全部打乱 / 全部收回、刷新页面，都会重新计时。
- 顶栏左上角原来的日期（点开是日历，可以换一天来拼）目前隐藏了，代码都还在：
  把 `src/state/store.ts` 里的 `PICK_ANY_DAY` 改回 `true`，顶栏的日期和日历就回来，拼好后的「明天再来」也换回「接着拼下一天」按钮（选过的日子不会被记住，刷新后回到今天）。
  恢复之后的用法照旧：顶栏显示带年份的完整日期，点它打开日历换一天，日历底部的「今天」回到今天，换成另一天就是重新开始；
  日历打开时也能用键盘：方向键按天 / 按周挪，`PageUp` / `PageDown` 换月（加 `Shift` 换年），`Enter` 收起。
- 左上角「已放入 n / 10」旁边那个按钮的名字跟着拼盘变：拼盘里一块都没有时叫「全部打乱」，点一下就把托盘里的拼块重新撒一遍；
  拼盘里已经放了拼块时叫「全部收回」，这会丢掉进度，所以先问一句，再点一次才执行。
- 整个窗口都是桌面，顶栏只是盖在它上方的一层：顶栏空着的地方也能把拼块拖进去放着，再从那里拿起来。
  拼块拖出窗口的任何一边，松手就弹回来，离上、下、左、右四条边留的是同一道边（12px，和拼垫离窗口最近处的留边一样），
  窗口是宽是窄都一样；边距按拼块画出来的样子量，松手后那点歪斜、手机托盘里缩小的尺寸都算在内。
- 顶栏左上、右上有字的地方不能压：松手时压住了，拼块就像出了界一样弹开，往旁边或往下，哪边近走哪边，并和文字留出同样的一道边；
  拼块的缺口正好让开文字时不用挪。原地旋转、翻面后压到文字，或者按钮的字变长（「确定全部收回？」）伸到旁边的拼块底下，拼块也会自己让开。
- 每开一局（打开或刷新页面、全部打乱 / 全部收回），十块拼块都会重新随机撒在托盘里：
  位置、朝向（转了几下）、微微的歪斜每次都不一样，但不会压在一起，也不会挤在一角、留出大片空白。
  翻面不随机，撒出来的都是正面朝上。
- 「提示」「看答案」两个按钮目前隐藏了，功能还在（store 里的 `showHint` / `showAnswer`），要用时在 `src/ui/TopBar.tsx` 里加回按钮即可。
  十块都放进去却拼错时，结果面板里的「看看哪块不对」仍会指出是哪块。

## 拼盘与拼块

拼盘的格子、缺口、刻字内容都照实物照片（`docs/1.jpg`–`docs/4.jpg`）来，边框和两处刻字为了好看略作调整：
四周边框一样宽，连右上角缺口拐弯的那两段也是，比实物略宽一点，顶上的标题才不挤；
标题刻在六个月份的正上方，和格子里的月份、日期一样大，左下角那句「每天都要拼一拼」略小一点，两处字分量相当。

```
1月  2月  3月  4月  5月  6月
7月  8月  9月  10月 11月 12月
1日  2日  3日  4日  5日  6日  7日
 …                          …
29日 30日 31日 星期日 星期一 星期二 星期三
               星期四 星期五 星期六
```

共 50 格。十块拼块是 7 个五格（L、N、P、T、U、V、Z）加 3 个四格（一字、L、S），合计 47 格，正好留出 3 格。
三张已拼好的照片被逐格描下来做成了测试数据，确认拼块形状与实物一致（照片里 N 形是翻过面的，所以翻面是必需的操作）。

求解器验证过：**12 个月 × 31 天 × 7 个星期的全部 2562 种组合都有解**（`src/game/solver.test.ts`）。

拼块的木色比拼盘略深一点。每块上还有两三处淡淡的痕迹：浅褐色的晕斑、顺着木纹的细灰线、小节疤，
像真木块上那样。每块的痕迹各不相同，但固定不变，刷新页面也还是那几处（`src/ui/WoodDefs.tsx`）。

## 技术选型

- **React 19 + Vite + Tailwind CSS 4 + TypeScript**
- **motion**（原 Framer Motion）：只用它的弹簧动画和 motion value。拼块的位置、角度、翻面都是 motion value，
  拖动时直接改值、不触发 React 重渲染；松手吸附、绕手指旋转、3D 翻面都是可打断的弹簧动画。
  只加载最小的 `domMin` 特性包。
- **拖拽用原生 Pointer Events + pointer capture**，没有用 dnd-kit / react-dnd：它们面向「放进某个容器」的列表式拖放，
  而这里需要拖动中旋转、绕抓握点转动、按格子吸附这类自由摆放的控制。鼠标、触屏、手写笔是同一套代码。
- **zustand** 管理棋局状态；规则部分（落点、旋转、翻面、叠放、提示）都是纯函数，单独测试。
- **antd 的 DatePicker**：顶部换日期用的日历（目前随日期一起隐藏），也是唯一用到的 antd 组件。
  它连同 antd 是用到才加载的：隐藏期间页面不会去下载，打开开关后，要显示日期时才取。按路径引入（`antd/es/date-picker`），
  不会把整个 antd 打进来；配色换成了拼垫的深绿底、粉笔字（`src/ui/DateField.tsx`）。
  打包时 antd（连同它带进来的 dayjs 等）和 React 各自单独成一个文件，游戏代码更新后浏览器仍能沿用它们的缓存。
- 礼花画在一块临时盖在页面上的 canvas 里（`src/ui/confetti.ts`），没有引入库，也没有图片：
  每片彩纸受空气阻力、会翻面露出背面的深色、左右飘着往下落，放完就把 canvas 撤掉；它不挡鼠标，放的时候照样能点。

## 目录

```
src/
  game/            规则与数据（纯 TypeScript，有测试）
    board.ts         拼盘格子、刻字、日期 ↔ 格子
    pieces.ts        十块拼块
    geometry.ts      旋转 / 翻面 / 坐标变换
    placement.ts     松手时的吸附
    state.ts         落下、旋转（含挪位）、翻面、完成判定、提示
    stacking.ts      叠放：按画出来的样子判断一块是否压着另一块
    room.ts          散放的拼块能待的范围：出了窗口、压了顶栏文字时，最近该挪到哪
    solver.ts        精确覆盖求解器（位运算 + 区域剪枝，单次 < 30ms）
    layout.ts        桌面横排 / 手机竖排的布局
    scatter.ts       每局把拼块随机撒进托盘：先随机落下，再互相推开、铺匀
    testing/         照片里描下来的三组解，以及测试用工具
  state/           zustand store（只在内存里，不存档）
  ui/              拼盘、拼块、顶栏、玩法指引、拼好后的面板与礼花等组件
```
