# 日历拼图

照着实物 1:1 复刻的网页版日历拼图：一块刻着 月 / 日 / 星期 的拼盘，十块木拼块。
每天把十块全部放进拼盘，只露出当天的「几月、几号、星期几」三格。

纯前端，没有任何网络请求，进度自动存在浏览器里。

## 运行

```bash
npm install
npm run dev      # 开发，默认 http://localhost:5173
npm run build    # 打包到 dist/，静态文件可直接部署
npm test         # 规则与求解器测试
```

## 怎么玩

| 操作 | 鼠标 / 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | 按住拖动 | 拖动 |
| 旋转 | 单击（绕点到的那一格转）、滚轮、`E` / `Q` | 轻点；拖着时另一根手指轻点 |
| 翻面 | 右键、`F` | 选中后点上方的「翻面」 |
| 微调 | 方向键（一次一格） | — |
| 放回 | `Esc`（拖动中按下则回到拿起的位置） | — |

- 拖到拼盘上方时会用虚线标出落点，靠近空位时拼块会被轻轻吸过去，松手就卡进格子。
- 在拼盘里旋转或翻面时，如果原地放不下，会自动挪到 2 格以内放得下、且仍压着你点的那一格的位置；实在放不下就搁在拼盘上面，等你再挪。
- 顶部可以换日期（点日期打开日历，或用 ‹ ›）。「提示」会帮你放好一块，或指出哪块挡了路；「看答案」直接摆好全部。
  「看答案」「全部收回」在会丢掉进度时先问一句，再点一次才执行。

## 拼盘与拼块

拼盘尺寸、缺口、刻字位置都量自实物照片（`docs/1.jpg`–`docs/4.jpg`）：

```
1月  2月  3月  4月  5月  6月
7月  8月  9月  10月 11月 12月
1日  2日  3日  4日  5日  6日  7日
 …                          …
29日 30日 31日 星期日 星期一 星期二 星期三
               星期四 星期五 星期六
```

共 50 格。十块拼块是 7 个五格（L、N、P、T、U、V、Z）加 3 个四格（一字、L、S），合计 47 格，正好留出 3 格。
三张已拼好的照片被逐格描下来做成了测试数据，确认拼块形状与实物一致（照片里 N 形是翻过面的，所以翻面是必需的操作）。

求解器验证过：**12 个月 × 31 天 × 7 个星期的全部 2562 种组合都有解**（`src/game/solver.test.ts`）。

## 技术选型

- **React 19 + Vite + Tailwind CSS 4 + TypeScript**
- **motion**（原 Framer Motion）：只用它的弹簧动画和 motion value。拼块的位置、角度、翻面都是 motion value，
  拖动时直接改值、不触发 React 重渲染；松手吸附、绕手指旋转、3D 翻面都是可打断的弹簧动画。
  只加载最小的 `domMin` 特性包。
- **拖拽用原生 Pointer Events + pointer capture**，没有用 dnd-kit / react-dnd：它们面向「放进某个容器」的列表式拖放，
  而这里需要拖动中旋转、绕抓握点转动、按格子吸附这类自由摆放的控制。鼠标、触屏、手写笔是同一套代码。
- **zustand** 管理棋局状态；规则部分（落点、旋转、翻面、提示）都是纯函数，单独测试。
- 音效用 Web Audio 现场合成，没有音频文件。

## 目录

```
src/
  game/            规则与数据（纯 TypeScript，有测试）
    board.ts         拼盘格子、刻字、日期 ↔ 格子
    pieces.ts        十块拼块
    geometry.ts      旋转 / 翻面 / 坐标变换
    placement.ts     松手时的吸附
    state.ts         落下、旋转（含挪位）、翻面、完成判定、提示
    solver.ts        精确覆盖求解器（位运算 + 区域剪枝，单次 < 30ms）
    layout.ts        桌面横排 / 手机竖排的布局
    testing/         照片里描下来的三组解，以及测试用工具
  state/           zustand store 与本地存档
  ui/              拼盘、拼块、顶栏等组件
```

## 依赖源

开发时 npm 官方源连不上，依赖是从 `registry.npmmirror.com` 装的，`package-lock.json` 里记录的也是这个地址。
需要换回官方源时，删掉 `package-lock.json` 重新 `npm install` 即可。
